# Identidade Visual — Descompila

Paleta e diretrizes extraídas das logos em [`/logos`](../logos), estilo pixel-art que remete a terminal/código, sóbrio o suficiente para passar confiança.

## Paleta de cores

| Nome              | Hex       | Uso                                      |
|--------------------|-----------|-------------------------------------------|
| Azul profundo       | `#154C63` | Textos de destaque, ícones, modo escuro    |
| Azul destaque       | `#2FAFDD`| Links, botões, acentos, hover              |
| Texto / tinta       | `#0F2E3D` | Corpo de texto em fundo claro              |
| Fundo claro         | `#F5F9FB` | Background padrão                          |
| Superfície / cards  | `#FFFFFF` | Cards, header, componentes elevados        |
| Borda               | `#DCE8ED` | Divisores, contornos sutis                 |

Modo escuro (quando existir): inverter para fundo `#0B1E28`, superfícies `#112C39`, texto `#E9F4F9`, mantendo o azul destaque como acento em ambos os temas.

## Tipografia

- **Títulos e corpo**: IBM Plex Sans — gratuita, boa cobertura de acentuação em português.
- **Rótulos, datas, badges técnicos**: IBM Plex Mono — ecoa o símbolo `</>` da logo sem forçar estética "hacker".

## Uso das logos

- Versão azul (`logo_azul_*`) sobre fundos claros; versão branca (`logo_branca_*`) sobre azul profundo ou em modo escuro.
- Símbolo isolado (caneca com `</>`) como favicon e avatar de redes sociais.
- Versão horizontal com o nome por extenso no cabeçalho do site.
- Exportar um SVG limpo do símbolo para favicon/app icons em vez de reamostrar o PNG existente, evitando serrilhado em telas de alta densidade.
